# Angular Material Palette Generator

[![npm](https://img.shields.io/npm/v/angular-material-palette-generator)](https://www.npmjs.com/package/angular-material-palette-generator)
[![license](https://img.shields.io/npm/l/angular-material-palette-generator)](./LICENSE)

Fine-tune the color palettes of your Angular Material 3 theme, tone by tone, and export them as a drop-in replacement
for the Sass file generated by `ng generate @angular/material:theme-color`.

**[Try it online →](https://avine.github.io/angular-material-palette-generator)**

```scss
$_palettes: (
  primary: (
    // 👇 This tool helps you refine this Sass map, for each palette
    0: #000000,
    10: #001d33,
    // ...
    40: #00639d,
    // ← pin your brand color here, it becomes `--mat-sys-primary` in light mode
    // ...
    100: #ffffff,
  ),
  secondary: (...),
  tertiary: (...),
  neutral: (...),
  neutral-variant: (...),
  error: (...),
);
```

## Features

- **Pin any color at any tone**: the palette goes exactly through your brand colors, every other tone is interpolated.
- **Predictable contrast**: tones are perceptual lightness (CIE L\*), as in Material Design 3.
- **Always displayable**: saturation is relative to the sRGB gamut, so no color gets clipped.
- **Token-aware preview**: each tone lists the `--mat-sys-*` tokens using it, with their WCAG contrast compliance.
- **Live preview**: apply the palettes to real Material components, or to the whole page.
- **Light and dark**: tune each color scheme separately.
- **Snapshots**: save up to 5 variants per palette and switch between them.
- **Round trip**: the exported Sass file embeds its settings, paste it back to resume the tuning.

## How palettes are generated

A palette goes exactly through the colors you pin (the _anchors_). By default, it has a single anchor: its key color,
pinned at its own tone. For each tone, the color is computed in the OKLCH color space from 3 values:

| Value          | Definition                                                          | Between anchors                     |
| -------------- | ------------------------------------------------------------------- | ----------------------------------- |
| **Tone**       | CIE L\*, from `0` (black) to `100` (white)                          | Smoothly shifted (see below)        |
| **Saturation** | Ratio of the maximum chroma available in sRGB for this tone and hue | Interpolated                        |
| **Hue**        | OKLCH hue                                                           | Interpolated along the shortest arc |

When an anchor is pinned at a tone that does not match its own lightness (e.g. a light brand color pinned at tone
`40`), the lightness of the surrounding tones is smoothly shifted so that the palette still goes through the anchor.
Saturation naturally decreases towards black and white. Exported colors are hex colors.

## Using the tool

1. **Select** a palette (`primary`, `secondary`…) and a color scheme (light or dark).
2. **Pin** a color: click the pin icon next to a tone, then edit the color in the form. Click again to unpin.
   In the form, you can also add or remove anchors and choose their tone ("Auto" pins a color at its own tone).
3. **Inspect** a color: hover or focus its hex value to see its tone, saturation and hue.
4. **Fix** the issues listed by the form (e.g. two anchors at the same tone, or anchors whose lightness is not in the
   same order as their tones).
5. **Check** the tokens of each tone and their contrast compliance.
6. **Export**: click "Copy Sass file to clipboard".

Settings are saved in the browser (`localStorage`).

## Export and import

The exported file has the same structure as the one generated by the Angular CLI (`$_palettes`, `$_rest`,
`$primary-palette`, `$tertiary-palette`), and its header mentions the color scheme. Export one file per color scheme,
then use them like the generated file:

```scss
@use '@angular/material' as mat;
@use './theme-colors-light' as light;
@use './theme-colors-dark' as dark;

html {
  @include mat.theme(
    (
      color: (
        primary: light.$primary-palette,
        tertiary: light.$tertiary-palette,
        theme-type: light,
      ),
    )
  );
}

html.dark-theme {
  @include mat.theme(
    (
      color: (
        primary: dark.$primary-palette,
        tertiary: dark.$tertiary-palette,
        theme-type: dark,
      ),
    )
  );
}
```

To resume the tuning of a color scheme, paste the whole file in the "Import settings" dialog.

## Embedding in your app

Prefer to tune your palettes against your own components? Embed the tool in your Angular app.

```bash
npm install angular-material-palette-generator
```

**Requirements**: Angular and Angular Material `^22.0.0`, an Angular Material theme defined with `mat.theme()`, and
an icon font registered for `<mat-icon>` ([Material Symbols](https://fonts.google.com/icons)).

### Full-page tool

```ts
import { Component } from '@angular/core';
import { PaletteGenContainerComponent } from 'angular-material-palette-generator';

@Component({
  selector: 'app-palette-generator',
  imports: [PaletteGenContainerComponent],
  template: `
    <pg-palette-gen-container>
      <!-- Optional: your own components, previewed with the generated palettes -->
      <app-my-showcase />
    </pg-palette-gen-container>
  `,
})
export class PaletteGenerator {}
```

Without projected content, a showcase of Material components is displayed. Use `hideLogo` to hide the logo.

### Floating overlay

Add a floating button on top of any page of your app, to tune the palettes while browsing it:

```ts
import { Component, DestroyRef, inject } from '@angular/core';
import { PaletteGenOverlayService } from 'angular-material-palette-generator';

@Component({/* ... */})
export class App {
  constructor() {
    const overlay = inject(PaletteGenOverlayService);
    overlay.enable();
    inject(DestroyRef).onDestroy(() => overlay.disable());
  }
}
```

The overlay applies the palettes to the whole page (`<body>`) while it is enabled.

### Preview on a specific element

Import `PaletteGenRendererDirective` to apply the generated `--mat-sys-*` tokens to any element:

```html
<section pgPaletteGenRenderer>...</section>
```
